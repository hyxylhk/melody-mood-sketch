# 07 · 腾讯云 CloudBase 云托管部署步骤（照着点就行）

> 目标：把 `cloudbase_deploy.zip` 变成一条**公网可访问**的链接，
> 用来填黑客松表单的 05「作品 demo 链接」（必填）。
> 全程约 10 分钟，其中 5~8 分钟是云端构建，不用盯。

---

## 0 · 出发前

| 项 | 值 |
|---|---|
| 要上传的包 | 项目根目录 `cloudbase_deploy.zip`（54 个文件 / 8.7 MB，含 Dockerfile） |
| 不要用 | GitHub 仓库 zip（带 `.git`、`docs/`，云端构建会失败或变慢） |
| 账户要求 | 腾讯云账号**余额为正**（充 ¥10 即可，实际只花几毛） |
| 应用端口 | 8000（Dockerfile 已写死，控制台也要填 8000） |

---

## 1 · 开通云开发环境

1. 打开 <https://tcb.cloud.tencent.com/dev>
2. 用微信 / QQ 扫码登录腾讯云
3. 首次使用点「**新建环境**」
   - 环境名称：随便填，如 `melody`
   - 计费方式：选「**按量计费**」（先不买包月套餐；免费额度 3000 资源点/月也有）
   - 地域：默认（上海 / 广州都行）
4. 环境创建好后，进入这个环境的控制台

> 若提示余额不足：右上角「费用中心 → 充值」，充 ¥10 足够。

---

## 2 · 新建云托管服务

左侧菜单 → 「**云托管**」（CloudBase Run）→ 「**新建服务**」

| 配置项 | 怎么填 |
|---|---|
| 部署方式 | **本地代码**（上传本地代码包） |
| 代码包 | 选 `cloudbase_deploy.zip` |
| 服务名称 | `melody-mood-sketch` |
| **访问类型** | **WEB（公网访问）** ← 必须选这个，不然没有公网域名 |
| **监听端口** | **8000** ← 默认 80，必须改！ |
| CPU | 0.25 核（最小规格，够用） |
| 内存 | 0.5 GB（平台要求内存 = 2 × CPU，选 0.25 核就对应 0.5 GB） |
| 副本模式 | **高可用** → 最小实例数 **1**（推荐），见下方说明 |
| 最大实例数 | 1（单人作品，1 个够了；怕评委同时点可以填 2） |
| 流量策略 | **部署完成后自动开启 100% 流量** |
| 环境变量 | **不用填**（Dockerfile 里已经写好了） |

### 关于「最小实例数」怎么选

| 模式 | 表现 | 花费 |
|---|---|---|
| 低成本 / 最小 0 | 连续 30 分钟没人访问就缩到 0，下次访问**冷启动约 30 秒**，且数据会重置回演示数据 | 不访问≈0 |
| **高可用 / 最小 1（推荐）** | 常驻，点开秒开，数据不会丢 | ≈¥0.72/天，到 10-09 约 ¥1.5 |

**为什么推荐最小实例 1**：云托管容器是**无状态**的，缩到 0 后
容器文件系统清空，容器重启会重新灌演示数据 —— 评委自己写的日记会没。
比赛这两天常驻只要一块多，评审完再改回 0 或直接删服务即可。

## 3 · 等构建（5~8 分钟）

点「确定 / 开始部署」后会依次经历：
**构建镜像（pip 装依赖）→ 推送镜像 → 部署版本 → 启动实例**

- 状态变成「**正常运行**」即成功
- 失败就看「构建日志」：九成是 `pip` 拉包超时，**重试一次**基本就过

---

## 4 · 拿到公网链接

服务详情页顶部会有**默认公网域名**，形如：

```
https://melody-mood-sketch-xxxx-1234567890.ap-shanghai.app.tcloudbase.com
```

这就是要填进表单 05 的链接。

---

## 5 · 验收（3 个检查点）

1. 浏览器打开域名 → 首页出来、情绪轨迹日历有颜色格子（说明 seed 数据灌进去了）
2. 打开 `域名/api/health` → 应返回
   `{"status":"ok","app":"Melody Mood Sketch",...}`
3. 写一条日记 → 出情绪 + 出音乐 → 点播放能出声 → 点 🗑 看粉碎动效

**第三条一定要做**：它同时验证了曲库（17 首 mp3）有没有真的带上去。

---

## 6 · 出问题怎么查

| 现象 | 原因 | 处理 |
|---|---|---|
| 访问 502 / 打不开 | 监听端口填了 80 | 改回 **8000** 重新部署 |
| 构建失败 | pip 网络超时 | 重试；还不行把 CPU 调到 0.5 核 |
| 页面白屏但 `/api/health` 正常 | `frontend/` 没进包 | 重新跑 `python scripts/build_deploy_zip.py` |
| 播放没声音 / 404 | `storage/library/*.mp3` 没进包 | 检查 zip 里 `storage/library/` 有 18 个文件 |
| 首页空白、无演示数据 | `scripts/` 被 `.dockerignore` 排掉了 | 已修过（不能排除 `scripts/`），确认包里有 `scripts/seed_demo.py` |
| 首次访问转圈 30 秒 | 冷启动 | 切高可用、最小实例 1 |

---

## 7 · 用完怎么停

- 想省钱：服务详情 → 「服务配置」→ 副本模式改「低成本 / 最小 0」
- 想彻底停：云托管服务列表 → 删除服务
- 环境不用了：环境设置里删除环境

费用参考（0.25 核 0.5 GB 常驻）：
CPU `0.055 元/(核·时) × 0.25` + 内存 `0.032 元/(GB·时) × 0.5` ≈ **¥0.03/小时 ≈ ¥0.72/天**；
外网出流量 ¥0.8/GB，一次完整访问约 2 MB，可忽略。
