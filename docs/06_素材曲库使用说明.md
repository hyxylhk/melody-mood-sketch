# 素材曲库使用说明

> 解决"生成的配乐不好听"：把真实音乐放进曲库，系统就会**优先播放素材**，
> 没有匹配素材时才降级为本地合成。
>
> 官方解疑文档（Q2）明确了两条合法路线：**公版免费歌曲** 和 **官方素材歌单**
> （比赛期间仅用于赛事评审演示，不商用、不对外发布）。

---

## 两条路线怎么选

| | 路线一：公版免费曲库（已内建） | 路线二：官方歌单素材 |
| --- | --- | --- |
| 状态 | ✅ **已经建好，34 首可直接用** | 需单曲购买拿标准格式 |
| 许可 | CC-BY 4.0（免费商用，需署名——已代办） | 官方背书，仅限比赛期间演示 |
| 音质 | 器乐无人声，氛围向，贴情绪 | 华语流行歌曲 |
| 用时 | 一条命令 | 逐首购买约 ¥30~80 |

两条路线**可以同时用**：曲库目录里谁在就播谁，互不冲突。

## 路线一：公版免费曲库（推荐，已内建）

音乐来自 Kevin MacLeod (incompetech.com)，1443 首中按官方情绪标签 + BPM + 描述
自动挑选了 34 首（17 种情绪 × 2 首），全部器乐、全部 CC-BY 4.0。

```bash
# 重建/补全曲库（断点续传，可反复跑）
python scripts/build_free_library.py --plan          # 先看选曲方案
python scripts/build_free_library.py                 # 下载
python scripts/build_free_library.py --per-emotion 1 # 只要 17 首（省时）
```

选曲逻辑完全可解释（呼应项目创新点）：每首歌按
`官方 feel 标签命中 ×3 + 描述关键词命中 ×2 + BPM 区间 ×2` 打分取最高。
例如《Gymnopedie No. 2》（萨蒂经典，BPM 77）→ tenderness 温柔；
《Volatile Reaction》（BPM 155，Aggressive）→ anger 愤怒。

**署名义务已代办**：曲库目录里有 `ATTRIBUTION.txt`（曲目+ISRC 清单），
页面页脚已加"曲库音乐: Kevin MacLeod (incompetech.com) · CC BY 4.0"。
答辩 PPT 建议在致谢页再放一次，展示版权意识。

## 路线二：官方歌单素材（补充）

⚠️ **`.mgg` 文件不能用**：这是 QQ 音乐 VIP 专属的 DRM 加密容器（文件头无任何
标准音频标识，整个内容是密文），只有 QQ 音乐客户端能解，浏览器 `<audio>` 播不了。
下载目录里那份《拷贝后其他播放器不可播放的解决方案.txt》说的就是这件事。

**拿标准格式的办法（官方指定）**：单曲购买后重新下载。
不建议全买 151 首——Demo 只需要覆盖 17 种情绪各 1 首，挑 10~17 首即可（约 ¥30~80）。

拿到 `.mp3 / .m4a / .flac / .wav / .ogg` 后用导入工具：

```bash
python scripts/import_library.py --dry-run   # 预览（默认源目录是 VipSongsDownload）
python scripts/import_library.py             # 导入，自动按 151 首映射表打情绪标签
```

> 顺带说明：如果用的不是官方歌单而是网易云/酷狗下载的文件，
> `.ncm / .kgm / .vpr / .tm0 / .xm` 同样是加密格式，脚本也会识别并跳过。

## 命名规则（两条路线通用）

`{情绪代号}_{随便起的名字}.{后缀}`，例如：

```
storage/library/
├── joy_Batty McFaddin.mp3            ← 路线一自动生成
├── sadness_At Rest.mp3               ← 路线一自动生成
├── joy_01_晴天.mp3                    ← 路线二手动/脚本导入
└── ATTRIBUTION.txt                   ← 路线一生成的署名清单
```

页头「音乐通道」会显示 `素材曲库 N 首`；曲库为空时照常走本地合成。

## 匹配规则

```
写日记 → 情绪识别结果 X
    │
    ├─ 曲库里有 X_ 前缀的素材？ ──→ 随机挑一首直接播放（provider = library）
    ├─ 没有 X，但有 unknown 素材？ → 兜底随机一首
    └─ 都没有                   → 本地算法合成（provider = local）
```

想关闭曲库优先（纯用合成器）：在 `.env` 里加 `MUSIC_LIBRARY_FIRST=False`。

## 常见问题

| 现象 | 原因 / 解决 |
| --- | --- |
| **放了素材但播不出声** | 十有八九是 `.mgg` 这类加密格式，回看本文档开头；换标准音频即可 |
| 放了素材但没被选中 | 检查文件名前缀是不是 17 个情绪代号之一；看页头「素材曲库 N 首」数字对不对 |
| 导入脚本说"映射表里查不到" | 文件名写法特殊，往 `song_emotion_map.json` 补一条再跑 |
| 想让某情绪固定用某一首 | 同一情绪放多首时会**随机**挑；只想用一首就只放一首 |
| 素材太长想截短 | 任意音频剪辑工具截 30~60 秒即可，系统不校验时长 |
| 换歌了但页面还是旧的 | 曲库是每次选歌实时扫描的；若是播放地址，浏览器缓存了音频，强制刷新一次（Ctrl+F5） |
