# 打包提交与部署方案

> 面向黑客松提交场景：先能**一键跑起来**，再能**给评委一个公网链接**，最后是**交付包怎么打**。

---

## 一、提交前自检清单（逐项打勾）

```bash
# 在项目根目录执行
cd emotion-music-diary

# 1) 依赖可安装
python -m pip install -r requirements.txt

# 2) 全部单元测试通过（47 项）
python -m pytest -q

# 3) 一键启动
python run.py
#    浏览器应自动打开 http://127.0.0.1:8000

# 4) 另开一个终端跑端到端冒烟（36 步）
python scripts/smoke_test.py
```

**交付前必须确认的 5 件事**：

- [ ] `.env` 里**没有**真实密钥被提交（提交前删掉 `.env`，只保留 `.env.example`）
- [ ] `storage/audio/*.wav` 的测试产物已清理（这些是运行时垃圾，不该进 git）
- [ ] `server.log` / `__pycache__` / `.pytest_cache` 不在包里（`.gitignore` 已覆盖）
- [ ] 用 `python run.py` 从**全新目录**能跑通（验证没有依赖当前工作目录的隐藏 bug）
- [ ] 断网状态下再跑一次 `run.py`，确认本地音乐引擎仍能出声（这是兜底能力的证明）

## 二、方案 A：本地演示（**首选，评委现场最稳**）

```bash
python run.py
```

`run.py` 会自动完成：检查依赖 → 检查/创建 `.env` → 初始化数据库 → 启动 uvicorn → 打开浏览器。

- 前端页面：`http://127.0.0.1:8000`
- 接口文档：`http://127.0.0.1:8000/docs`
- 数据文件：`storage/diary.db`
- 音乐产物：`storage/audio/*.wav`

**现场保险做法**：`.env` 中设置 `MUSIC_PROVIDER=local`、`LLM_PROVIDER=auto`。
断网时 LLM 自动降级到规则引擎，音乐永远走本地合成 → **无网也能完整演示**。

## 三、方案 B：局域网共享（队友 / 评委用自己手机访问）

```bash
python run.py --host 0.0.0.0 --port 8000
```

先查本机局域网 IP：

```powershell
# Windows
ipconfig | findstr IPv4
```

假设得到 `192.168.1.23`，把 `http://192.168.1.23:8000` 发给同 WiFi 的人即可。
前端 `app.js` 里 `API_BASE` 默认是同源相对路径，**无需任何改动**。

> 若访问不了，多半是 Windows 防火墙拦了 8000 端口，临时关闭防火墙或放行该端口即可。

## 四、方案 C：免费云部署（给评委一个公网链接）

> 重要提醒：以下免费平台**文件系统是临时的**，重启后上传/生成的音频可能丢失。
> 提交演示链接时建议：**音乐用本地引擎 + 短时长**，并在 README 里注明"演示环境数据为临时存储"。
> 生产环境请改用对象存储（COS/S3）持久化音频，改 `music_service.py` 里保存产物的那一段即可。

### C1. Render（推荐，最省心，支持原生 Python）

> **仓库里已经放好了 `render.yaml`（Blueprint 配置）**，所以现在只需要三步：
>
> 1. 把项目 push 到 GitHub（**曲库片段 `storage/library/*.mp3` 必须一起提交**，
>    共约 9MB —— 曲库已改为随仓库走，云端才有真歌可放；`.gitignore` 已配置好）
> 2. <https://render.com> → **New + → Blueprint** → 选中仓库 → **Apply**
> 3. 等构建完成，拿到 `https://xxx.onrender.com`
>
> `render.yaml` 里已写好构建/启动命令和 `PYTHON_VERSION`、`MUSIC_LIBRARY_FIRST`；
> `LLM_API_KEY` 标记为 `sync:false`，部署时在 Render 网页上手动填（不填也能跑，
> 情绪分析自动降级为本地规则）。

手动配置（不用 Blueprint 时参考）：

| 字段 | 值 |
| --- | --- |
| Runtime | Python 3 |
| Build Command | `pip install -r requirements.txt` |
| Start Command | `uvicorn backend.main:app --host 0.0.0.0 --port $PORT` |
| Instance Type | Free |

> 免费实例 15 分钟无访问会休眠，首次唤醒约 50 秒。把链接发给评委之前，
> 自己先访问一次"热机"。
> 免费实例无持久磁盘：重新部署后 SQLite 清空。比赛演示用
> `python scripts/seed_demo.py --load` 灌入 30 天演示数据即可。

### C2. Railway

1. <https://railway.app> → **New Project → Deploy from GitHub repo**
2. 平台会自动识别 Python 项目；在 **Settings → Start Command** 填：
   `uvicorn backend.main:app --host 0.0.0.0 --port $PORT`
3. **Variables** 里加与上面相同的环境变量
4. 生成域名即可访问

### C3. Hugging Face Spaces（Docker，适合展示 AI 属性）

仓库里加一个 `Dockerfile`：

```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
ENV MUSIC_PROVIDER=local
CMD ["uvicorn", "backend.main:app", "--host", "0.0.0.0", "--port", "7860"]
```

> HF Spaces 默认暴露 **7860** 端口，所以这里必须写 7860（不是 8000）。

## 五、方案 D：打成离线交付包（评委离线评审场景）

### D1. 源码包（最通用，推荐）

```powershell
# Windows PowerShell，在项目根目录执行
Compress-Archive -Path * -DestinationPath ../MelodyMoodSketch-src.zip -Force
# 记得先删掉 .env、storage/audio/*.wav、server.log
```

或命令行：

```bash
zip -r ../MelodyMoodSketch-src.zip . -x "*/__pycache__/*" "*/.pytest_cache/*" ".env" "storage/audio/*" "server.log"
```

### D2. 单文件可执行包（评委机器上没 Python 也能跑）

用 PyInstaller 把整个服务（含前端静态资源）打成一个 exe：

```bash
pip install pyinstaller
pyinstaller --onefile --add-data "frontend;frontend" --name MelodyMoodSketch run.py
# 产物在 dist/MelodyMoodSketch.exe，双击即可启动
# 注意：--add-data 的分隔符 Windows 用 ; ，Linux/macOS 用 :
```

> 打包后 `.env` 需与 exe 放同一目录；首次运行会自动建库。

## 六、目录打包范围说明

**必须包含**：

```
backend/          # FastAPI 全部源码
frontend/         # index.html / styles.css / app.js
storage/          # 空目录即可，运行自动建库
tests/            # 47 项 pytest 用例
scripts/          # 初始化 + 端到端冒烟脚本
docs/             # 启动、测试、答辩、部署四份文档
requirements.txt
run.py            # 一键启动
pytest.ini
.env.example      # 配置模板（不含真实密钥）
README.md
```

**必须排除**：

```
.env              # 真实密钥
storage/diary.db  # 本地数据，属于个人隐私
storage/audio/*   # 运行时产物
server.log
__pycache__/ .pytest_cache/
```

## 七、常见问题速查

| 现象 | 原因 / 解决 |
| --- | --- |
| `ModuleNotFoundError: backend` | 必须在**项目根目录**执行命令（`run.py` 所在层） |
| 端口被占用 | `python run.py --port 8080` 换端口 |
| 前端能开但生成一直转圈 | 看 `server.log`；大概率合成耗时较长，把 `MUSIC_DURATION_SECONDS` 调小到 15 |
| 音频 404 | 确认 `storage/audio` 目录存在且进程有写权限 |
| 云端平台重启后音乐没了 | 免费平台临时文件系统，属预期行为；生产改用对象存储 |
| LLM 一直走规则兜底 | 检查 `.env` 里 `LLM_API_KEY` 是否填写、`LLM_PROVIDER` 是否为 `llm` 或 `auto` |
| 想完全不出网 | `LLM_PROVIDER=rule` + `MUSIC_PROVIDER=local`，全链路本地运行 |
