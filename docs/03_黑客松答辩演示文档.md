## 第 1 页｜一句话讲清项目（Slogan）

**"写下的情绪，值得被听见。"**

旋律情绪速写（Melody Mood Sketch）是一款 旋律情绪速写：
用户只需写一段今天的文字，系统自动理解文字背后的情绪，并为这段情绪**即时生成一首独一无二的背景音乐**，
让每一篇日记都带上自己的主题曲，可回放、可追踪、可回顾整段情绪曲线。

- 输入成本：**一句话**（不需要选标签、不需要懂乐理）
- 输出价值：**一首只属于这一刻的歌** + 一份可量化的情绪档案

## 第 2 页｜问题与洞察（为什么要做）

| 现状痛点 | 我们的洞察 |
| --- | --- |
| 文字日记"写了就沉底"，没有回看的动力 | 情绪需要**感官载体**，音乐是最低门槛的情绪容器 |
| 想配 BGM 只能手动搜歌单，匹配靠感觉、不精准 | 情绪 → 音乐参数的**映射可以被建模**（调式/速度/音区/织体） |
| 现有音乐生成工具面向"创作者"，不是"记录者" | 面向**普通人的私密记录场景**，才是高频需求 |
| 情绪管理工具（心情打卡）枯燥、难坚持 | 加一层"**生成专属音乐**"的奖励反馈，留存动机立刻变强 |
| 音乐生成 API 有成本/额度限制，demo 容易翻车 | 必须做**双引擎 + 本地兜底**，断网也能完整演示 |

**一句话结论**：情绪日记缺的不是"记录入口"，而是"**让记录变得好听、值得回看**"的那一层。我们补的就是这一层。

## 第 3 页｜核心功能（现场演示四步走）

演示全流程 **约 30 秒**，评委可以亲眼看到从文字到声音的完整闭环：

1. **写**：在左侧输入框写一段日记（支持示例一键填充，现场直接点"示例·开心"）
2. **懂**：点击"生成我的主题曲" → 后端调用大模型解析情绪
   - 返回：主情绪（如 `joy`）、情绪强度（0~100）、情绪关键词、一句话情绪解读
3. **听**：系统按情绪参数实时合成音乐，页面显示"🎵 正在为你的情绪谱曲…"，完成后**自动播放**
   - 页面同时展示：情绪卡片（配色随情绪变化）、音乐参数卡（调式/BPM/音色）
4. **存 + 回看**：右侧"日记时间线"自动出现这条记录；点任意历史条目 → 立即重听当时的音乐
   - 顶部还有**情绪分布统计**（每种情绪各写了几篇）

**演示小贴士（现场稳定版）**：
建议演示前在 `.env` 里设置 `MUSIC_PROVIDER=local`，这样不依赖任何外部 API 额度，
全程 100% 可复现；如果现场网络好且已配好 LLM Key，就展示"大模型真实解析"这一版。

## 第 5 页｜技术亮点一：自研情绪 → 音乐参数映射（核心创新点）

这是整个项目**最有技术含量**的部分：不是"随机生成一段音乐"，而是建立了一套
**可解释的心理学/音乐学映射规则**，让每段音乐都"有理由地"符合情绪。

每种情绪被建模成一份 **EmotionProfile（情绪音乐画像）**，包含 9 个维度：

| 情绪 | 调式 | BPM | 音区 | 和声 | 织体 | 混响 | 听感 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 喜悦 joy | 大调 Lydian | 118 | 中高 | 明亮大七 | 琶音 | 短 | 上扬、跳跃 |
| 悲伤 sadness | 自然小调 | 62 | 中低 | 小七/挂四 | 长音铺底 | 长 | 缓慢、下坠 |
| 愤怒 anger | 弗里几亚 | 140 | 低 | 强力和弦 | 断奏 | 短 | 紧张、压迫 |
| 焦虑 anxiety | 半音阶 | 132 | 中 | 减和弦 | 碎拍 | 中 | 不安、悬置 |
| 孤独 loneliness | 多利亚 | 54 | 低 | 空五度 | 稀疏单音 | 极长 | 空旷、回响 |
| 疲惫 fatigue | 五声音阶 | 48 | 中低 | 柔和九 | 极简 | 长 | 松弛、催眠 |
| 怀念 nostalgia | 大调 | 76 | 中 | 大六/挂二 | 分解和弦 | 中长 | 温暖、朦胧 |
| 平静 calm | 大调 | 66 | 中 | 大九 | 平缓 | 长 | 呼吸感 |
| 心动 love | 大调 | 88 | 中高 | 大七/九 | 波浪 | 中 | 甜蜜、摇曳 |
| 振奋 excitement | 大调 | 150 | 高 | 大三 | 快速琶音 | 短 | 燃、推动 |

**为什么这是亮点**：评委追问"你的音乐凭什么叫符合情绪"时，可以逐条解释——
小调 = 悲伤、**慢 BPM = 低能量**、低音区 = 沉重、长混响 = 空旷孤独，
每条都有音乐心理学依据，而不是黑箱。

## 第 6 页｜技术亮点二：双音乐引擎 + 零依赖本地合成（工程亮点）

| | 云端引擎（可选） | 本地引擎（默认兜底） |
| --- | --- | --- |
| 依赖 | 外部音乐生成 API + Key | **零依赖**，只用 Python 标准库 |
| 成本 | 按次计费 | **0 元** |
| 网络 | 需要联网 | **断网可跑** |
| 生成耗时 | 10~60 秒 | **约 2~3 秒**（20 秒立体声 WAV） |
| 产物 | 远端音频 URL | 本地 `storage/audio/*.wav` |

**本地合成器做了什么**（`backend/services/local_composer.py`）：

1. **乐理建模**：按情绪画像取音阶 → 生成和弦进行 → 拆成「贝斯 / 和声垫 / 主旋律 / 打击」四个声部
2. **物理合成**：每个音符用「基频 + 泛音列」叠加做加法合成（谐波振幅按 `1/n` 衰减），而非刺耳方波
3. **包络 ADSR**：每个音符有起音—衰减—延音—释放，避免"咔哒"爆音
4. **节奏律动**：按 BPM 排布拍点，带轻微 swing（摇摆感），避免机械节拍器味
5. **空间感**：简易混响（多抽头延迟叠加）、立体声左右声像分离（宽声场）
6. **母带处理**：tanh 软限幅 + 峰值归一化到 -3dB 左右，**保证响度足够且不失真**
7. **确定性随机**：同一篇日记用同一随机种子 → **可复现**，演示结果稳定

> 答辩话术："我们把音乐生成做成了**可插拔 Provider**，云端是加分项，本地是保底项。
> 黑客松现场网络不可控，但我们的 demo **永远不会翻车**。"

## 第 7 页｜技术亮点三：完整的工程化质量（不是 demo 级代码）

一个人、两天、能交付到什么程度？这一页专门回答"**是不是能工程化**"：

| 工程维度 | 具体做法 |
| --- | --- |
| **分层清晰** | `routers`（接口）/ `services`（业务）/ `models`+`crud`（数据）/ `schemas`（契约）/ `config`（配置），职责单一 |
| **配置外置** | 所有密钥在 `.env`，代码里**零硬编码**；`.env.example` 提供模板 |
| **自动建表** | 服务启动时 `init_db()` 自动建库建表，不需要手工执行任何 SQL |
| **类型与校验** | 全链路 Pydantic Schema，请求/响应都有类型约束与示例 |
| **跨域处理** | 已开启 CORS，前端独立端口访问后端不报错 |
| **异步任务** | 音乐生成走后台任务 + 任务表状态机（`pending → running → done/failed`），前端轮询，不阻塞请求 |
| **容错兜底** | LLM 不可用 → 本地规则解析；音乐 API 不可用 → 本地合成；**任一外部依赖挂掉系统仍可用** |
| **测试覆盖** | **47 项 pytest 用例**（情绪解析 / API 契约 / 合成器音频质量）+ **36 步端到端冒烟脚本** |
| **音频质检** | 测试里真的读 WAV 波形，校验峰值、RMS、通道数、采样率、动态变化，杜绝"生成了但没声音" |
| **一键启动** | `python run.py` 一条命令拉起服务并自动打开浏览器 |

## 第 8 页｜数据与商业模式（产品视角）

**数据资产**（这是最值钱的部分）：
每一篇日记 = 「时间戳 + 文本 + 情绪标签 + 情绪强度 + 音乐参数指纹」
→ 长期累积就是一份**结构化的用户情绪曲线**，是纯音乐 App 拿不到的高价值数据。

**可延展场景**：

- 📈 **情绪周报 / 月度心情曲线**：告诉用户"你周三最焦虑"，是天然的留存钩子
- 🎧 **歌单反向生成**：把过去一个月的情绪日记，串成一张"你的人生原声带"
- 🧠 **心理健康辅助**：长期情绪趋势异常时温和提醒（需谨慎合规）
- 🤝 **社交轻互动**：匿名"情绪共鸣"（同一时刻有人和你一样失眠）
- 🎵 **与腾讯音乐生态结合**：情绪 → 匹配曲库相似曲目做"AI 生成 + 真人作品"混合推荐；
  生成的音乐作为原创内容沉淀进平台 UGC 池
