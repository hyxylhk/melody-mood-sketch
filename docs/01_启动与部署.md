# 01 · 启动与部署说明

本文档覆盖四种运行形态，从本地演示到线上 Demo 都有路线。

| 方案 | 适用场景 | 成本 | 难度 |
|------|----------|------|------|
| ① 本地直跑 | 开发、现场答辩（推荐） | 0 | ⭐ |
| ② 局域网分享 | 让同一 WiFi 下的手机/评委电脑访问 | 0 | ⭐ |
| ③ Docker | 保证环境一致、交给别人复现 | 0 | ⭐⭐ |
| ④ 免费云部署 | 提交作品需要一个公网链接 | 0 | ⭐⭐⭐ |

---

## 方案 ① 本地直跑（最推荐）

### Windows

```bat
:: 双击 启动.bat 即可；或在命令行里：
cd /d D:\code\emotion-music-diary

:: 1) 建虚拟环境（只需一次）
python -m venv .venv
.venv\Scripts\activate

:: 2) 装依赖（只需一次）
pip install -r requirements.txt

:: 3) 复制配置模板并填密钥（没有密钥可跳过）
copy .env.example .env

:: 4) 启动
python run.py
```

> **关于编码**：Windows 下如果出现中文乱码，先在命令行执行 `chcp 65001` 切到 UTF-8。
> 本项目所有源码都是 UTF-8 编码。

### macOS / Linux

```bash
cd ~/code/emotion-music-diary
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python run.py
```

### 等价的手动命令

如果你想绕开 `run.py`（比如要加自己的参数）：

```bash
python -m uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

区别：`run.py` 额外帮你做了「依赖检查 → 自动生成 .env → 创建目录 → 自动建表 → 自动开浏览器」。

## 方案 ② 局域网分享（手机也能访问）

1. 修改 `.env`：

```ini
APP_HOST=0.0.0.0
APP_PORT=8000
CORS_ORIGINS=*
```

2. 查本机内网 IP：

```bash
# Windows
ipconfig          # 找「IPv4 地址」，形如 192.168.1.23
# macOS / Linux
ifconfig | grep inet
```

3. 同一 WiFi 下的设备浏览器打开 `http://192.168.1.23:8000`

> 若连不上，多半是 Windows 防火墙拦了 inbound。
> 解决：防火墙 → 允许应用通过 → 勾选 Python；或临时关闭公用网络防火墙（演示后记得恢复）。

## 方案 ③ Docker 部署

已提供 `Dockerfile`，一条命令打包：

```bash
docker build -t emo-music-diary:1.0 .
docker run -d --name emo -p 8000:8000 \
  -e LLM_API_KEY=sk-你的密钥 \
  -e LLM_BASE_URL=https://api.deepseek.com/v1 \
  -e MUSIC_PROVIDER=local \
  -v $(pwd)/storage:/app/storage \
  emo-music-diary:1.0
```

访问 `http://127.0.0.1:8000`。

> `-v $(pwd)/storage:/app/storage` 把数据和音频挂到宿主机，
> 容器删掉也不会丢失历史日记。

## 方案 ④ 免费云服务部署

### 推荐：Render（对个人项目免费，支持 Dockerfile）

1. 把代码推到 GitHub（**确认 `.env` 没有被提交上去**！检查 `.gitignore`）
2. 打开 https://render.com → New → Web Service → 关联该仓库
3. 配置如下：

| 配置项 | 值 |
|--------|-----|
| Environment | `Docker` |
| Instance Type | `Free` |
| Health Check Path | `/api/health` |

4. 在 Environment Variables 里添加：

```
LLM_API_KEY      = sk-你的密钥
LLM_BASE_URL     = https://api.deepseek.com/v1
LLM_MODEL        = deepseek-chat
MUSIC_PROVIDER   = local
APP_DEBUG        = False
APP_PORT         = 8000
CORS_ORIGINS     = *
```

5. Deploy，拿到形如 `https://emo-music-diary.onrender.com` 的公网地址。

> ⚠️ **免费版的坑**：Render Free 实例 15 分钟无访问会休眠，首次访问要等 30~50 秒冷启动；
> 另外免费实例的磁盘是临时的，**重启后 SQLite 数据和生成的音频会丢失**。
> 演示建议：答辩前先访问一次把服务唤醒；数据持久化请升级付费实例或改用外部数据库。

### 备选：Railway

已提供 `Procfile`，Railway 会自动识别：

```
web: uvicorn backend.main:app --host 0.0.0.0 --port $PORT
```

### 备选：Hugging Face Spaces（Docker SDK）

适合做 Demo 展示页，步骤与 Render 类似，把 `Dockerfile` 放仓库根目录，SDK 选 Docker，端口填 8000。

## 环境变量完整说明

全部写在 `.env`（模板见 `.env.example`），改完**必须重启服务**才生效。

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `APP_DEBUG` | `True` | 开发用 True（改代码自动重启）；上线务必 `False` |
| `APP_HOST` | `0.0.0.0` | 监听地址 |
| `APP_PORT` | `8000` | 端口 |
| `DATABASE_URL` | `sqlite:///./storage/diary.db` | 数据库路径，改 MySQL 只需改这一行 |
| `AUDIO_DIR` | `./storage/audio` | 生成的音频存放目录 |
| `CORS_ORIGINS` | `*` | 跨域白名单，逗号分隔；上线改成具体域名 |
| `LLM_BASE_URL` | `https://api.deepseek.com/v1` | OpenAI 兼容接口的 base url |
| `LLM_API_KEY` | 空 | 留空 → 自动降级本地关键词分析 |
| `LLM_MODEL` | `deepseek-chat` | 模型名 |
| `LLM_TIMEOUT` | `30` | 大模型请求超时（秒） |
| `LLM_FALLBACK_ENABLED` | `True` | 调用失败是否自动降级 |
| `MUSIC_PROVIDER` | `auto` | `auto` / `local` / `httpapi` |
| `MUSIC_API_BASE_URL` | 空 | 第三方音乐 API 地址 |
| `MUSIC_API_KEY` | 空 | 第三方音乐 API 密钥 |
| `MUSIC_MAX_WAIT_SECONDS` | `120` | 云端生成的最长等待时间 |
| `MUSIC_DURATION_SECONDS` | `24` | 本地合成的音乐时长（秒） |
| `MUSIC_SAMPLE_RATE` | `44100` | 采样率，机器慢可降到 22050 |

**各家大模型 base_url 速查**（都是 OpenAI 兼容格式，改一行就能换）：

| 厂商 | LLM_BASE_URL | LLM_MODEL 示例 |
|------|--------------|----------------|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| 月之暗面 Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` |
