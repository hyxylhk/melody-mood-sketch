## 一、作品介绍 & 创作思路（定稿，246 字）

> 下面是可直接粘贴的定稿版。相比你的初稿只做了 4 处措辞修正（理由见下一节），语义与信息量完全一致，**纯汉字正好 246 字**。

当下很多年轻人习惯记录情绪日记，但纯文字难以描摹细腻瞬时的内心感受；普通音乐平台需要手动检索背景音乐，很难快速匹配当下的心情。本项目是面向青年群体的轻量化 AI 音乐情绪日记 H5 网页工具。用户输入今日的心情文字，经由大模型完成文本情绪识别，输出情绪标签；程序根据标签自动匹配对应的短氛围旋律，作为听觉情绪载体。用户可以在页面查看、播放旋律，并以卡片形式在本地保存一条条"文字—旋律"情绪日记，留存自己的情绪轨迹。产品开箱即用，无需下载客户端。项目内置降级兜底策略，不依赖不稳定的外部音乐生成接口，保障 Demo 演示稳定，为情绪记录提供一种听觉化的全新表达方式。

## 二、核心功能（提交表"功能说明"字段）

| 功能 | 说明 |
| --- | --- |
| 一句话写日记 | 输入今日心情文字，支持一键填充示例，无需选标签、无需懂乐理 |
| AI 情绪识别 | 大模型结构化输出主情绪 + 情绪强度（0~100）+ 关键词 + 一句话解读 |
| 情绪旋律匹配 | 按情绪标签映射音乐参数（调式 / BPM / 音区 / 和声 / 织体 / 混响），实时生成专属旋律 |
| 在线播放 | 生成完成自动播放，可暂停、拖动进度、重新播放 |
| 卡片式日记本 | 每条日记以卡片保存（文字 + 情绪 + 旋律），点击任意卡片可回听当时的旋律 |
| 情绪轨迹 | 顶部统计各情绪篇数，形成可视化的情绪变化轨迹 |
| 本地存储 | SQLite 持久化，数据存本机，隐私不出户 |
| 免安装 | H5 网页，手机 / 电脑浏览器直接打开，无需下载客户端 |

**情绪覆盖**：共 **17 种**——喜悦、悲伤、愤怒、焦虑、孤独、疲惫、怀念、心动、振奋、感恩、希望、感动、释然、压力大、温柔、迷茫、平静（neutral），每种都有独立的音乐参数画像。

## 三、技术方案（提交表"技术实现"字段）

- **前端**：原生 HTML + CSS + JavaScript，零框架零构建，通过 `fetch` 调用 REST API，轮询获取生成进度
- **后端**：Python FastAPI，分层为 路由层 / 服务层 / 数据层 / 契约层；自带 `/docs` 交互式接口文档
- **AI 能力**：大模型做文本情绪结构化解析（JSON 输出），失败自动降级到本地规则引擎（关键词加权 + 程度副词 + 否定词 + 标点特征）
- **音乐生成**：可插拔 Provider 架构。云端音乐 API（可选）+ **自研零依赖本地合成引擎**（默认）
  - 本地引擎纯 Python 标准库：加法合成（基频 + 泛音列）、ADSR 包络、BPM 律动与 swing、多抽头混响、立体声声像、tanh 软限幅归一化
  - 20 秒立体声 WAV，**约 2~3 秒生成完毕**，确定性随机种子保证可复现
- **存储**：SQLite + SQLAlchemy ORM，服务启动自动建表，零运维
- **工程规范**：密钥全部外置 `.env`、全链路 Pydantic 类型校验、已开启 CORS、异步任务状态机、47 项单元测试 + 36 步端到端冒烟脚本、`python run.py` 一键启动

## 四、创新点（提交表"创新性"字段，3 条）

1. **听觉化的情绪载体**：把"文字日记"升级为"文字—旋律"双通道记录，让抽象情绪第一次有了可回听的声音档案，解决纯文字"记完就沉底、不想回看"的痛点。
2. **可解释的情绪→音乐映射**：不是随机生成，而是建立了「情绪 → 调式 / 速度 / 音区 / 和声 / 织体 / 混响」的多维映射规则（如悲伤=小调+62BPM+长混响，振奋=大调+150BPM+高音区），每一段旋律都"有理由地"符合情绪，可解释、可调优。
3. **双引擎 + 降级兜底**：自研零依赖本地合成引擎作为默认通道，云端音乐 API 作为可选升级项，统一 Provider 接口，改一个环境变量即可切换。**不依赖外部接口、断网也能完整运行**，从根本上保障 Demo 稳定性。

## 五、目标用户与场景

- **核心用户**：18~30 岁有情绪记录习惯、但不愿为"写日记"付出高成本的青年群体
- **典型场景**：睡前 30 秒写下今天 → 立刻听到属于自己的一段旋律 → 一周后回听，被当时的情绪击中
- **延伸场景**：情绪周报 / 月度心情曲线、把一个月日记串成"人生原声带"、与音乐平台曲库结合做"AI 生成 + 真人作品"混合推荐
